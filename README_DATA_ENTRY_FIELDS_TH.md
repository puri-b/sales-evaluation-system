# เพิ่มฟิลด์ในงานบันทึกข้อมูล

## สิ่งที่เพิ่ม

ปุ่ม **+ เพิ่มฟิลด์** พร้อมชื่อฟิลด์, Data Type (`number`, `date`, `text`),
หมายเหตุรายฟิลด์ และหมายเหตุรวม
แสดงตารางในหน้าสรุปและหน้าพิมพ์

เพิ่มได้สูงสุด 100 ฟิลด์; ชื่อ 200 ตัวอักษร;
หมายเหตุรายฟิลด์ 2,000; หมายเหตุรวม 5,000

## ก่อนนำขึ้นระบบจริง

1. **สำรองฐานข้อมูล** และสร้าง branch ใหม่
2. ทดสอบกับฐานข้อมูลทดสอบก่อน ไม่ใช่ฐานจริง
3. เปิด `sql/003_data_entry_fields.sql` ใน DBeaver ตรวจฐานข้อมูลและ schema `X_SalesApp`
   แล้ว Execute Script **ทั้งไฟล์**
4. รัน `sql/003_verify_data_entry_fields.sql` เพื่อตรวจผล และสิทธิ์ของ role ที่แอปใช้ (`DB_USER`)
5. ทดสอบ Vercel Preview โดยตั้ง Environment Variables ให้ชี้ฐานทดสอบ
6. เมื่อทดสอบผ่าน ให้รัน SQL บน Production **ก่อน Deploy แอป**

```bash
npm ci
npm test
npm run build
```

**ถ้า SQL มี error ห้าม Deploy ต่อ** ให้ตรวจสอบและแก้ไขก่อน

## ผลการทดสอบ

ผ่าน Unit/API tests 39 กรณี และ Browser tests 11 รายการ
โดยใช้ข้อมูลจำลอง (mock)
ยังไม่ได้ทดสอบกับ PostgreSQL จริง และยังไม่ได้ Deploy

**Production build ยังยืนยันไม่ได้**
เพราะสภาพแวดล้อมนี้ดาวน์โหลด SWC ไม่สำเร็จ
ต้องรัน build และทดสอบบนเครื่องหรือ Vercel Preview ก่อนใช้งานจริง

## การย้อนกลับ

กลับไปใช้แอปเวอร์ชันก่อนหน้า
แต่ **คงตารางและคอลัมน์ใหม่ไว้** เพื่อไม่ให้ข้อมูลที่บันทึกไว้หาย

## ไฟล์ที่ควรอ่าน

- `docs/DATA_ENTRY_FIELDS.md`: รายละเอียดทางเทคนิค SQL, API, สิทธิ์ฐานข้อมูล และการ Deploy
- `docs/TEST_RESULTS.md`: ผลทดสอบและข้อจำกัด
- `CHANGE_MANIFEST.txt`: รายการไฟล์ที่เพิ่ม/แก้ไข

ชุดไฟล์นี้ **ไม่รวม `.env.local`** ให้ใช้ค่า Environment Variables เดิมบน Vercel
ไฟล์ `.env.example` เป็นเพียงตัวอย่าง ห้ามใช้แทนค่าจริง
